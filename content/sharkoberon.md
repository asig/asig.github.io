My 1998/1999 diploma thesis at ETH Zurich: an implementation of [Oberon System 3](https://en.wikipedia.org/wiki/Oberon_(operating_system)) for the [SHARK Network Computer](https://www.computerhistory.org/collections/catalog/102711028).

SharkOberon boots over the network using TFTP, and includes development tools, basic Internet tools, a RAM disk for local storage and soft floating point support. It is based on Native Oberon V2.3.2 and the Oberon-1 compiler for the Ceres.
