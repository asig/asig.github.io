Oberon Disk Image Tool: a command-line tool for working with Native Oberon disk images on modern operating systems.

It can list files, read files from an image to the host, write host files into an image, show file information (size, creation time, disk location), and mount an image as a FUSE file system for direct access. Written in Go.
